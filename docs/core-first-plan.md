## 1. 产品定位

EasyRead 是一个**简单小说阅读器**。核心链路唯一主线：

```
导入书源 → 书源列表(启用/禁用) → 搜索 → 详情 → 阅读
  （翻页/滚动、进度续读、缓存、换源、净化、基础排版设置）
```
