# EasyRead（易读）产品设计方案

> 版本：v1.0
> 日期：2026-08-04
> 状态：已批准

---

## 一、产品定位

一款面向深度阅读爱好者的**轻量级开源电子书阅读器**，核心逻辑为「工具本体 + 用户自主导入书源」，产品本身不提供任何书籍内容、不内置书源、不运营内容平台，仅作为内容解析与阅读载体。

### 核心原则

- **极致纯净**：零广告、零推送、零内置书城
- **安全透明**：全量代码开源，所有数据本地存储
- **生态兼容**：兼容阅读3.0书源规则，无缝复用社区书源

---

## 二、技术选型

| 维度 | 决策 | 理由 |
|------|------|------|
| **框架** | Flutter 3.x (Dart) | 跨平台开发效率高，热重载迭代快 |
| **架构** | Feature-first + Clean Architecture | 模块边界清晰，适合多人协作，支持后续插件化 |
| **状态管理** | Riverpod + Provider | 依赖注入+Dependency Override 天然支持 Clean Architecture |
| **本地存储** | Hive (KV) + ObjectBox (关系型) | Hive 存书架/设置/书源元数据，ObjectBox 存章节缓存 |
| **网络层** | Dio + 中间件链 | 频率控制、UA 轮换、自动重试、书源级可配置 |
| **渲染方式** | 纯 Widget 渲染（自研 TextPainter） | 60fps 翻页、即时主题切换、毫秒级启动 |
| **书源引擎** | 兼容阅读3.0规则格式 | 直接复用社区数千个书源，降低用户迁移成本 |
| **设计风格** | 极简主义 + iOS 风格视觉（MD3 底层） | 内容优先，精致但不突兀 |

## 三、项目架构

### 3.1 整体目录结构

```
lib/
├── core/                          # 全局基础设施
│   ├── theme/                     # iOS 风格主题系统
│   ├── network/                   # Dio + 中间件链
│   ├── router/                    # 路由配置
│   ├── database/                  # Hive + ObjectBox 初始化
│   └── purification/              # 三阶段净化管线引擎
├── features/
│   ├── bookshelf/                 # 书架模块
│   │   ├── data/
│   │   │   ├── repositories/      # 仓库实现
│   │   │   └── models/            # 数据模型
│   │   ├── domain/
│   │   │   ├── entities/          # 核心实体
│   │   │   └── repositories/      # 仓库接口
│   │   └── presentation/
│   │       ├── pages/             # 页面
│   │       ├── widgets/           # 可复用组件
│   │       └── providers/         # Riverpod 状态管理
│   ├── book_source/               # 书源管理模块
│   ├── search/                    # 搜索模块
│   ├── reader/                    # 阅读器内核模块
│   └── settings/                  # 设置模块
└── app.dart                       # 应用入口
```

### 3.2 模块间依赖规则

- `core` ← `features`：任何 feature 可依赖 core
- features 之间禁止互相 import
- domain 层禁止依赖任何第三方框架
- 跨模块通信通过 core 内定义的接口契约实现

### 3.3 数据流方向

```
UI (Widget) → Provider (Riverpod) → UseCase → Repository (接口) → DataSource (Hive/ObjectBox/Dio)
```

数据单向流动，domain 层零框架依赖。

## 四、功能模块详细设计

### 4.1 书架模块

- **展示**：网格/列表双视图切换，封面+书名+最新章节+进度条+最后阅读时间
- **排序**：按阅读时间/书名/加入时间，支持置顶
- **进度管理**：四重维度存储（书籍ID+章节索引+段落偏移+滚动位置），每3秒自动保存
- **批量管理**：多选删除、批量分组、一键清空、自定义分组标签
- **本地导入**：TXT/EPUB 格式，自动解析目录+编码识别，SAF 框架兼容 Android 13+

### 4.2 书源管理模块

- **导入方式**：本地 JSON 文件批量、网络订阅链接（定期更新）、剪贴板、二维码
- **管理功能**：列表展示、搜索排序、启用/禁用、批量校验
- **编辑功能**：JSON 语法高亮编辑器、实时字段校验、测试执行
- **订阅更新**：增删改订阅源、更新频率设置、增量更新、变更记录

### 4.3 搜索模块

- **多源聚合搜索**：并发分发到所有启用书源，异步返回结果，去重合并排序
- **单源搜索**：指定单个书源精确搜索
- **智能换源**：当前源加载失败→自动尝试下一个可用源，切换时保留阅读位置
- **换源面板**：底部展示各源章节数/状态，支持手动切换和多源内容对比

### 4.4 阅读器内核（核心壁垒）

**渲染管线：**

```
原始 HTML → 三阶段净化 → 解析为 Node 树 → 分页布局 → TextPainter 渲染
```

**翻页模式：**
| 模式 | 实现方式 | 特点 |
|------|---------|------|
| 上下滚动 | ListView 虚拟化 | 无限滚动，零内存增长 |
| 左右翻页 | PageView 逐页 | 三页缓存，预加载 |
| 仿真翻页 | CustomPainter 手绘 | 页角卷曲动画 |

**排版自定义：**
- 字体：选择/字号(12~32sp)/字重，支持自定义字体族
- 排版：行间距(1.0~2.0)、段间距、首行缩进、两端对齐
- 主题：日间/夜间/护眼绿/羊皮纸 + 自定义主题 + 阅读灯
- 交互：点击翻页、音量键翻页、长按选词笔记、进度跳转

**缓存策略：**
- 内存缓存：当前章节全文 + 前后各1章元数据 + 最近10章索引
- 磁盘缓存：ObjectBox，以「书籍ID+章节索引」为 key，上限500章自动淘汰
- 预加载：进入章节自动预加载后2章，翻到倒数第3章时继续预加载

### 4.5 内容净化系统（三阶段管线）

| 阶段 | 功能 | 配置层级 |
|------|------|---------|
| 1. 标签净化 | 移除广告标签、script、style、无意义 div | 内置规则（全局生效） |
| 2. 正则净化 | 用户自定义替换规则 | 书源级 + 用户级 |
| 3. 排版整理 | 统一段落格式、缩进、对齐 | 内置规则（全局生效） |

### 4.6 设置模块

- **外观**：4套预设主题 + 自定义主题色 + 阅读灯
- **阅读**：默认翻页模式、动画速度、音量键翻页、点击区域配置
- **数据**：本地 JSON 备份、WebDAV 云同步、自动定时备份
- **网络**：代理配置、超时时间、并发限制、UA 自定义

## 五、UI/UX 设计规范

### 5.1 设计语言

极简主义 + iOS 风格视觉，以 MD3 作为底层框架，视觉上按 iOS Human Interface Guidelines 定制：

- **导航栏**：Large Title 风格，毛玻璃效果
- **卡片**：无边框、大圆角、精细留白
- **字体层级**：SF Pro 风格字重体系
- **色彩**：低饱和度中性色为主，强调色点缀
- **深色模式**：纯黑背景（#000000）

### 5.2 页面交互细节

| 页面 | 交互特征 |
|------|---------|
| 书架 | Large Title 导航栏、右侧「编辑」按钮、长按弹出快速操作 |
| 阅读 | 纯黑/纯白/仿纸背景、点击中间弹出面板、底部滑出进度条、右滑返回 |
| 设置 | Inset Grouped 列表、底部弹出式 Picker、毛玻璃 NavigationBar |
| 搜索 | 自动聚焦搜索框、实时建议、分组展示结果、加载进度指示器 |

## 六、异常处理策略

| 异常类型 | 核心策略 |
|---------|---------|
| 网络异常 | 无网络→离线缓存、超时→自动重试3次（间隔递增）、DNS/SSL→降级提示 |
| 内容解析异常 | 解析失败→返回原始 HTML、规则失效→提示用户、编码错误→自动轮询 |
| 存储异常 | 写入失败→降级 Hive、磁盘满→自动清理、数据库损坏→修复+恢复备份 |
| 运行时异常 | 全局 ErrorWidget 兜底、OOM→回收50%缓存、崩溃→启动时恢复位置 |

## 七、MVP 迭代计划（5 周）

### Phase 1：基建与核心链路（第 1~2 周）

1. 项目脚手架搭建（Flutter 初始化、目录结构、Riverpod、路由、主题框架）
2. 存储层就绪（Hive + ObjectBox 初始化、Repository 接口定义）
3. 网络层 + 书源解析引擎（Dio 封装、阅读3.0规则解析、净化管线 MVP）
4. 书源导入 + 单源搜索

✅ **里程碑**：可导入书源 → 搜索关键词 → 看到搜索结果列表

### Phase 2：阅读器内核（第 3~4 周）

1. 内容解析渲染管线（HTML→Node树→分页→渲染）
2. 翻页模式实现（上下滚动 + 左右翻页）
3. 阅读进度管理（四重维度持久化、断点续读）
4. 主题系统（日间/夜间模式、基础排版设置）

✅ **里程碑**：搜索→进入阅读→翻页→切换主题→退出续读，全链路闭环

### Phase 3：功能完善与打磨（第 5 周）

1. 多源聚合搜索 + 智能换源
2. 书架管理（网格/列表视图、进度条、排序分组、批量操作）
3. 章节缓存 + 预加载策略
4. 本地 TXT/EPUB 导入
5. UI 打磨（过渡动画、空状态/加载/错误状态、iOS 风格细节）

✅ **里程碑**：功能完整的 MVP 测试版 APK，可发布内测

### 9.2 书源规则兼容范围

兼容阅读3.0规则格式，覆盖以下核心字段：

- 搜索规则（searchUrl、bookList、bookName、bookAuthor、coverUrl、bookDetailUrl）
- 详情规则（detailUrl、bookName、author、coverUrl、intro、catalogUrl）
- 目录规则（catalogUrl、chapterList、chapterName、chapterUrl）
- 内容规则（contentUrl、chapterContent、净化规则、替换规则）
- 通用规则（header、cookie、encoding、userAgent、requestInterval）
